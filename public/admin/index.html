User Management

Create local kiwi-events-only admin users or link external host users to kiwi-events roles.

Admin only

Local vs external users

Local users exist only in kiwi-events and can log in to this Admin UI. External users already exist in a host system. kiwi-events only links them by external provider and external user ID.

Create local admin user

Local users are kiwi-events-only admin accounts. They can log in to this Admin UI and manage users/config, but they have no account or permissions in your external host system.

Link external host user

Use this when the user already exists in your main backend. The external user ID must be stable and come from that host system.

Storage

Configure local storage and optional public or private S3-compatible storage targets.

May require restart

Local storage is always available

If no storage target is specified for an upload, kiwi-events uses local storage. Public and private S3-compatible storage targets are optional and can be enabled independently.

Local filesystem storage

Files are stored inside the kiwi-events server or container below the configured upload directory.

Public S3-compatible storage

Use this target for files that should be directly reachable from a browser through a public URL.

Files stored in this target can be reached directly through the configured Public Base URL. Do not use it for content that should not be publicly accessible.

Private S3-compatible storage

Use this target for files that should only be read through authenticated S3 API requests from kiwi-events.

Kiwi-generated files

Choose where files generated by kiwi-events itself are stored.

Edit user

Update this kiwi-events EventUser.

The initial admin@admin user is protected. You can only change its password.

External user

This user is linked to an external host system. The host-system password is not known by kiwi-events. A password entered here creates or updates only a kiwi-events-local password.

Reset Kiwi Events?

This action cannot be undone.

The following data will be deleted:

  • Contents of the configured Kiwi Events database
  • Local uploads
  • Kiwi Events configuration
  • Saved secrets

Public and private storage objects will not be automatically deleted.
